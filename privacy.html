Privacy

Last updated 22 September 2026. This page describes the app; it says the same as Settings › Privacy inside MediaFlowSwift, which is the authoritative list and changes with the app.

The short version

MediaFlowSwift works on your Mac and your own network. It has no account, collects no usage data or analytics, and contacts no server of ours. Your media, projects and database stay on your Mac and on your network.

A few features need a service run by another company. Each one is off until you turn it on in Settings › Privacy, which shows what is sent, to whom, and what for. You can turn any of them off again at any time.

What stays on your network

  • Your network storage: finding it, connecting to it, reading and writing media, the shared database file and app updates.
  • Your database server, if you use one. That connection is not encrypted, so keep the server on a network you trust.
  • App updates come from a folder you choose, never from a web site.
  • A local model you point at another computer on your network receives the same frames or text as above and nothing more; an address on the internet is refused.

Problem reports sent to us

If you send a problem report to us, it is filed as an issue in our development tracker so that we can fix the fault. It contains only what the app showed you before you clicked Send. If you chose to include an email address for a reply, we use it for that reply and nothing else. We keep reports for as long as the fault is being worked on and for our release records afterwards.

This website

This site is static pages served by GitHub Pages. We run no analytics and set no cookies. GitHub, as the host, keeps ordinary server logs of requests (IP address, page requested, time) under GitHub’s privacy statement. Fonts are loaded from Google Fonts, which receives the request for the font files.

Purchases

When plans go on sale, payment will be handled by a payment provider; the checkout page will say which, and their privacy policy covers the card and billing details you enter there. MediaFlowSwift itself never sees card numbers.
